# Specs — observed contracts

These are **reverse-engineered contracts of code that already exists** (as of 2026-09-21),
not forward-looking designs. They record what each script *does* today, including behaviour
that is arguably wrong — defects are cross-referenced to `../tasks.md` rather than silently
corrected here. **VERIFIED** = read in the code or executed; **INFERRED** = flagged.
